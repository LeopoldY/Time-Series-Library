# 清洗后四台设备的聚类与模型分配

日期：2026-09-14。输入目录为 `dataset/fault_selected_cleaned`，仅设备27、58、69、83。读取现有清洗文件，未重新清洗、未修改源数据或算法代码、未训练预测模型。

## 方法

沿用上一轮四级12维口径：每级分别提取零值比例、均值、总体标准差/均值（均值≤1e-6时CV=0），StandardScaler后执行三簇KMeans，random_state=42，n_init=10。输入按设备27、58、69、83排序。按簇内四级零值比例的平均值升序命名Dense、Intermittent、Sparse，映射Informer、iTransformer、PatchTST。

本轮仅用四台清洗后设备重新拟合标准化器和聚类，不是将它们投到上一轮80台设备的固定中心。为区分清洗与样本集合变化的影响，同时以相同方法对四台未清洗设备独立重聚类，作为对照。

## 结果解释与使用边界

本轮清洗后模型分配与“仅四台原始设备重聚类”对照完全一致。因此，相比上轮80台设备结果，设备27和69的模型变化不能归因于清洗；样本集合变化已足以产生该分配。

设备69自身平均稀疏度高于设备83，但12维KMeans将69与27分到同簇；该簇平均稀疏度为0.941660，低于设备83所在簇的0.974113，所以被命名为Intermittent。这是按簇均值命名的结果，并非按单设备稀疏度直接排序。

- 四台设备分三个簇，仅有一簇包含两台，属于小样本相对分组；不能据此宣称某个模型预测效果最好。
- 清洗若删除正常区间，会改变稀疏度、强度和CV，路由描述的是清洗后分布。
- 非1小时间隔表示清洗后时间轴存在断点；后续小时预测构造窗口时不能跨断点把下一行直接当作下一小时。
- 使用全量时间段作设备画像；正式预测评估应只用训练段重新拟合，避免未来信息影响模型选择。
